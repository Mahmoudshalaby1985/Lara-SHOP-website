# 👑 Lara Shop

Welcome to **Lara Shop**, a modern and responsive e-commerce website designed for luxury shopping.  
The website showcases a premium collection of **watches, accessories, and perfumes** with an elegant and user-friendly interface.

---

## 🌟 Features

- 📱 Responsive design for all devices
- 🎨 Modern and elegant user interface
- 🖼️ Interactive image carousels
- ⌚ Luxury watches collection
- 💍 Accessories collection
- 🌸 Perfumes collection
- 🛒 Product cards with prices
- ✨ Smooth hover effects and animations
- 🧭 Easy navigation bar

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript**

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the `index.html` file in your preferred web browser.
3. Browse the collections and enjoy the shopping experience.

---

## 🎯 Project Purpose

This project was created to practice **front-end web development** by building a responsive online store with a modern luxury design using HTML, CSS, Bootstrap, and JavaScript.
